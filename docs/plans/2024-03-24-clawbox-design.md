# ClawBox 设计文档

## 概述

ClawBox 是 OpenClaw Gateway 的跨平台桌面 GUI 客户端，采用暗黑游戏风格设计，提供完整的 AI 代理管理、监控和配置功能。

## 技术栈

| 层级 | 技术 |
|------|------|
| 框架 | Tauri v2 |
| 后端 | Rust |
| 前端 | SvelteKit + Svelte 5 |
| 样式 | TailwindCSS 4 + Skeleton UI 3 |
| 状态管理 | Svelte runes ($state, $derived) |
| 多语言 | svelte-i18n + rust-i18n |

## 功能模块

### 1. 首页 (Dashboard)

**布局**:
- Gateway 状态卡片（启动/停止/重启）
- 今日使用统计（Token/API调用/任务）
- 最近会话快捷入口
- 快捷操作按钮

### 2. 聊天模块

**功能**:
- 多会话标签页，点击 + 新建会话
- 侧边面板：选择代理、模型、会话设置
- 支持 Markdown 渲染、代码高亮
- 流式输出实时显示
- 支持多行输入、快捷键发送

### 3. 配置管理

**子模块**:
| 标签 | 功能 |
|------|------|
| 模型配置 | 管理模型提供商、API Key、默认模型 |
| 渠道配置 | API 渠道、代理设置、负载均衡 |
| 代理配置 | Agent 个性、系统提示词、工具绑定 |
| 技能配置 | 已安装 Skills 列表、启用/禁用、参数配置 |

### 4. Agent 协作

**流程编排**:
- 拖拽节点（Agent、工具、条件、循环、输出）
- 连线配置
- 保存/运行流程

**消息追踪**:
- 时间线视图
- 消息内容详情
- 调用链路
- 耗时统计

### 5. 监控模块

**链路追踪**:
- 单次请求的完整调用链
- 耗时分析
- 瀑布图展示

**资源监控**:
- Token 消耗统计
- API 调用次数
- 平均响应时间
- 成功率
- 24小时趋势图

### 6. 任务管理

**任务列表**:
- 启用/禁用任务
- 立即运行
- 执行历史

**流程编排**:
- 拖拽节点
- 条件分支
- 触发器配置

**定时设置** (用户友好):
- 仅执行一次：日期+时间选择器
- 每隔固定时间：数字+单位选择
- 按计划执行：重复频率+时间+星期选择
- 后台自动转换为 Cron 表达式

### 7. 日志查看

**功能**:
- 左侧文件列表，带大小和时间
- 右侧内容查看
- 实时刷新
- 按级别筛选（INFO/WARN/ERROR）
- 关键词搜索
- 下载/清空日志

### 8. Skills 商店

**来源**:
- GitHub
- 官方市场
- npm/pypi 包管理器
- 自定义源

**展示**:
- 商店布局：左侧分类，右侧详情
- 分类维度：功能分类、热度分类、集成分类
- 卡片展示：评分、下载量、来源

**功能**:
- 一键安装，自动处理依赖
- 已安装列表管理
- Skill 详情弹窗

### 9. 自动安装

**检测项**:
| 检测项 | 检测方式 | 国内环境处理 |
|--------|----------|-------------|
| Node.js | `node --version` | - |
| OpenClaw | `openclaw --version` | 使用 npmmirror 镜像 |
| 网络环境 | 访问测试 URL | 自动切换镜像源 |
| 系统类型 | Tauri API | 不同系统不同安装脚本 |

**流程**:
1. 启动时自动检测所有依赖
2. 显示检测结果
3. 用户确认后开始安装
4. 实时显示安装进度和日志
5. 安装完成后进入主界面

**功能**:
- 智能镜像选择
- 进度展示
- 错误处理（重试/手动安装指引）
- 跳过选项（稍后在设置中安装）

### 10. 关于模块

**信息展示**:
- ClawBox 版本、构建信息
- OpenClaw Gateway 版本
- Node.js、Tauri 等依赖版本
- 系统信息（OS、架构、安装路径）

**更新功能**:
- 启动时自动检查更新
- 手动检查按钮
- 发现新版本时显示更新内容
- 下载进度展示
- 自动安装选项

## 多语言支持

支持语言：
- 中文 (zh-CN)
- 英文 (en-US)
- 可扩展更多语言

实现方式：
- 前端：svelte-i18n
- 后端：rust-i18n
- 根据系统语言自动选择

## 安全考虑

- API Key 等敏感信息存储在系统密钥链
- 配置文件加密存储
- 网络请求使用 HTTPS
- 本地通信使用 Tauri 安全 IPC
